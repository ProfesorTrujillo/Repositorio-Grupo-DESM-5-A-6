## Descripción del proyecto:
Sistema de gestión de inventario local para empleados que permite registrar y consultar productos de muebles, con sistema de alertas de bajo stock y vista catálogo para que el cliente pueda observar los productos.

## Tecnologías utilizadas:
- Angular
- TypeScript
- Node.js
- HTML
- CSS

## Instrucciones de ejecución:

### Backend:
1. cd backend
2. npm install
3. npm run dev

### Frontend:
1. cd frontend
2. npm install
3. ng serve
4. http://localhost:4200
