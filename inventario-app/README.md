## Descripción del proyecto
Aplicación web desarrollada con Angular 21 y Firebase que implementa un CRUD completo de productos, autenticación de usuarios y comunicación con APIs externas (EmailJS, WhatsApp, Facebook, X).

## Actividades integradas
- ✅ AA 3.3.1 - Configuración del entorno en Firebase
- ✅ AA 3.3.2 - Verificación y validación de Firebase
- ✅ AA 3.3.3 - Integración de Firebase en Angular 21.1.1
- ✅ AA 3.3.4 - Login y Registro con Firebase Authentication
- ✅ AA 3.5 - CRUD completo con Angular y Firestore
- ✅ AA 3.6 - Integración de APIs de Comunicación

## Tecnologías utilizadas
- Angular 21.1.1
- Firebase (Authentication + Firestore)
- EmailJS
- WhatsApp API
- Facebook Sharing API
- X (Twitter) Sharing API

## Pasos para ejecutar el proyecto

### Requisitos previos
- Node.js (versión 18 o superior)
- Angular CLI: `npm install -g @angular/cli`

### Instalación
```bash
# Clonar el repositorio
git clone https://github.com/ParisJXD/Repositorio-Grupo-DESM-5-A-6

# Entrar a la carpeta
cd Repositorio-Grupo-DESM-5-A-6

# Instalar dependencias
npm install

# Ejecutar la aplicación
ng serve -o
