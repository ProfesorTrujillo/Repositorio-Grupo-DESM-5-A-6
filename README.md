## Descripción del proyecto

Aplicación desarrollada en Angular que integra Firebase para la autenticación de usuarios, base de datos en Firestore y consumo de APIs externas. Permite a los usuarios registrarse, iniciar sesión y realizar operaciones CRUD dentro del sistema.

## Actividades integradas

* AA 3.3 Conociendo Firebase antes de Angular
* AA 3.3.1 Configuración del entorno en Firebase
* AA 3.3.2 Verificación y validación de Firebase
* AA 3.3.3 Integración de Firebase en Angular
* AA 3.3.4 Login y Registro con Firebase Authentication
* AA 3.5 CRUD completo con Angular y Firestore
* AA 3.6 Integración de APIs de Comunicación

## Tecnologías utilizadas

* Angular
* Firebase
* Firestore
* TypeScript
* EmailJS 

## Pasos para ejecutar el proyecto

1. Clonar el repositorio

2. Instalar dependencias:
   npm install

3. Ejecutar el proyecto:
   ng serve

4. Abrir en el navegador:
   http://localhost:4200
